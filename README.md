# Unknown Agent

You're unemployed with a laptop, a crypto wallet and an AI agent that bills you per word. Make rent.

The game lives in [`app/`](app/README.md) (TypeScript + Vite): `cd app && npm install && npm run dev`.
The world bible and timeline are the wiki in [`app/content/wiki`](app/content/wiki/README.md).

[`legacy/`](legacy/) holds the old prototype's story text and README. Not canon; kept as raw material.
